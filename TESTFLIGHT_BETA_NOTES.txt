Teacher Studio — Build 12 Family Desk (iOS source 1.2.0)

What is new
Today gives families six quick topics and gives teachers an action queue. Try a dated dismissal change, a callback, an announcement requiring acknowledgement, and an editable FAQ that opens the right form. All existing lesson tools, released-grade controls and encrypted teacher-material backups remain available.

Fictional local practice
Use invented children, guardians and school procedures. The new Family Desk requests, pickup verification, callback history and response indicators are local practice. Switching Teacher/Parent previews the same device; it is not authentication and does not deliver anything to a real family. A pickup code alone does not establish an adult's authorization.

Teacher review
- Check that pending dismissal changes leave the current confirmed plan visible.
- Log no answer or voicemail and confirm the callback remains open until explicitly resolved.
- Choose the message audience and whether a response is needed.
- Edit an FAQ, reopen the parent view and follow its action.
- Reopen existing classroom, math, grade-release and material-backup tools.

Parent review
- Select the fictional child and use the Today topics.
- Request a change for a specific date, then check the practice review status.
- Distinguish new, needs a reply, call requested and resolved.
- Read an announcement, then explicitly acknowledge it when required.
- Confirm that only teacher-released grades are visible.

Existing configured Family Connect pilot
The inherited Supabase features still support fictional account, invitation, assignment, released-grade and message tests on separate devices after setup. They do not make the new operational Family Desk records synchronize remotely. No background push delivery is included.

Package status
This is prepared application source plus an offline HTML demo. A signed iOS build, physical iPhone testing and TestFlight upload must be performed in the configured Apple/Codemagic environment; none is claimed by these notes.

# Teacher Studio roadmap after Build 4

## Delivered in current offline prototype
- Preserved core Build 3 capabilities: standalone HTML, mathematical generator, teaching kits, worksheets, games, teacher-led class customization, school hub, resources and lesson exchange.
- Added original fraction-guided diagnostics and fresh retests with correct-answer explanations, anonymous local results and explicit limitations.
- Added five editable original lesson methods with direct save to existing Lesson Exchange.
- Added private per-class teacher showcase / Remember Why / non-identifying text Legacy Wall, with export.

## Next iteration — Build 5 proposed
1. Strengthen standards: break fraction concepts into misconception-level checks; add multiple original visual model question types and question difficulty validation by teacher subject matter reviewers. Include the official state standard chosen by the teacher where a verified crosswalk exists; do not claim all grades/states are supported.
2. Save and revisit teaching kits without retyping; connect the original 'Teach It Better' lesson to the Classroom Kit creation flow. Add preview-and-print before any student usage.
3. Add separate classroom FAQs and teacher showcase display within My Classroom Page with drafts, teacher preview, and optional explicitly published fictional sections. Preserve zero student PII and easy hide/reorder controls.
4. Conduct real educator testing (20 diverse teachers): first useful task, minutes saved, curriculum fit, errors, trust and weekly repeat usage.

## Following iterations — require school authorization before real student use
- Account verification for teachers, guardians and school owners; mandatory permission checks on the server.
- A reliable school-owned events source and per-class announcements, teacher-approved results, private parent messages, and multi-device sync with retention/deletion and audit controls.
- Optional Google Classroom integration after district/organization approval; focus on avoiding double entry.
- A lesson-sharing network with teacher verification, rights/attribution and moderation.

## Research and business gates
- Test real classroom usability and learning measurement before asserting score improvements.
- Keep teacher and family access free by default; optional adult-only tips can support operations, but real cloud sync isn't guaranteed to stay free as adoption grows.
- Measure weekly active teachers, minutes saved, teacher satisfaction, repeat usage, and observed learning—not downloads alone.

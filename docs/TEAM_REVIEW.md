# Build 4 — simulated cross-functional review

This is a structured role-based critique created with ChatGPT. No external software team or panel of actual teachers has reviewed this build.

| Perspective | Completed / reviewed in this prototype | Priority for next test |
|---|---|---|
| Classroom teacher | Start diagnostic, receive worked corrections, reuse an original lesson, draft teaching story | Is the workflow faster than existing tools? |
| Math curriculum designer | Aligned example skills to grade 4/5 fraction domain references; original visual/number-line/critique approaches | Review mathematical explanations and standards scope with actual subject specialists |
| Assessment designer | Separate short diagnostic, practice and fresh retest; named no mastery certification | Validate item difficulty, misconceptions and measurement reliability |
| UI designer | Prominent 3-task navigation, locally saved edits, phone-width layout | Conduct task-based usability testing across grades and device restrictions |
| Software engineer | Preserved v3 modules, added growth.js/css, built standalone offline file and versioned PWA cache | Test PWA install, deployment reproducibility, restore/import and browser compatibility |
| Security/privacy reviewer | Local-only private memories, anonymous score records, fictional parent view | Separate deployment security review before real student information |
| Copyright reviewer | Original question generator and original lesson scaffolds; external references linked only | Verify all bundled graphics/licenses before public commercial distribution |
| Product strategist | Free-first teacher utility and emotional showcase, with no API dependency | Interview real teachers; test actual weekly retention and optional tips |

## Explicit exclusions

- No live cross-device parent access to new Build 4 features.
- No automatic grading of handwritten photos, teacher replacement, cloud AI prompts, or recurring AI API costs.
- No real standardized test score guarantee or claims that short demo quizzes establish mastery.
- No public alumni profiles, student tracking, or automatic publication of student work.
- No evidence yet that teacher testimonials, academic growth or customer willingness-to-tip have been independently measured.
